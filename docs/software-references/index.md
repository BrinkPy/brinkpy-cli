# Software and Library References

This section covers the Python packages that Brinkpy CLI and its backing API depend on. The two pages below are kept separate because they serve different purposes.

## Dependency Sets

- [CLI Dependencies and Citations](cli.md): packages users install locally to run Brinkpy CLI. Use this page if you need dependency-level software attribution in papers, reports, or technical notes.
- [API Library Credits](api.md): packages used internally by the Brinkpy API, documented here for software attribution. These are not installation requirements for CLI users.

## Citation Policy

- Brinkpy follows each package author's official citation instructions when they are available.
- If no formal citation guidance is published, Brinkpy cites the project's official documentation or PyPI page.

## Method References

- Method references are listed by topic in [Recommended Texts and References](../problem-authoring/recommended-texts.md).
- References for specific profile options, such as the SORM and importance sampling (IS) methods, also appear next to each option in the [Profile Options Reference](../profiles/profile-reference.md).
